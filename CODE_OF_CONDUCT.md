# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text at that link applies to every project space
(issues, pull requests, discussions, reviews, and any other channel used for this
project) and to anyone representing the project elsewhere.

## In short

- Be respectful and welcoming; assume good intent and give constructive feedback.
- No harassment, personal or political attacks, sexualised language or imagery,
  trolling, or publishing anyone's private information without permission.
- Focus on what is best for the project and the people using it.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[@BenjaminSRussell](https://github.com/BenjaminSRussell), through
[GitHub private vulnerability reporting](https://github.com/BenjaminSRussell/Scrapy/security/advisories/new)
(mark the report "Code of conduct"). If that form is not available, open an issue
titled **"Conduct contact request"** with no details and the maintainer will reply with
a private channel. Reports are kept confidential.

## Enforcement

The maintainer reviews every report and follows the Contributor Covenant 2.1
enforcement ladder: correction, warning, temporary ban, permanent ban. The
response depends on the severity and on whether the behaviour repeats.
