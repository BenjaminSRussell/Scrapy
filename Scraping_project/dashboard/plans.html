What this build meters

  • Daily budgets live in cost_controls: stage3_max_gpu_minutes_per_day, stage4_max_gpu_minutes_per_day, and stage4_max_ocr_pages_per_day. Null, or a missing block, does not stop the worker. A number stops that UTC day with budget_exhausted. The gauge is budget_remaining{stage,resource}.
  • HTTP cache quota is httpcache_max_bytes (default 2 GiB). 0 still reports size and does not prune.
  • The Redis high watermark is 10000, the same line as QueueBacklog (redis_queue_length above 10000). Connection settings stay REDIS_HOST, REDIS_PORT, REDIS_PASSWORD, and REDIS_DB.
  • Published objectives stay three: Stage 2 success at least 99% over 24h (Stage2SuccessSLO, no bool modifier), QueueBacklog above 10000, and KafkaConsumerLagSLO above 250000 messages. No fourth SLO.
