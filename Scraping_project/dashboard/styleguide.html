Job history table (#1023)

For the future Jobs tab. The header sticks inside .job-history-scroll. Add job-history-table--zebra for optional row striping; omit it for a plain table. Each sortable column is a <button type="button"> inside <th scope="col">, not a clickable header cell. aria-sort on the header is ascending, descending, or none.

Keyboard

  • Tab / Shift+Tab — move to a column sort button.
  • Enter or Space — cycle that column: ascending, then descending, then unsorted.
  • Arrow Left / Arrow Right — move focus between sort buttons. Does not change the sort and does not wrap.
  • Home / End — focus the first or last sort button.
